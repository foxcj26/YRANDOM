# YRANDOM v2.0.0.18 修改说明

> 发布日期：2026-11-21 · 基于上一版 v2.0.0.17 叠加

## 本次改动

- **插件更名为 YRANDOM（为规避 GitHub 仓库风控而改名）**：
  - 原 `YRAND` 名称触发 GitHub 仓库风控，为规避风控、保障仓库与后续 Release 可持续发布，插件更名为 **YRANDOM**；
  - `manifest.yml` 的 `name` 由 `YRAND` 改为 `YRANDOM`，插件描述同步以 YRANDOM 开头；
  - 设置页导航标题、悬浮窗窗口标题、悬浮窗 Tooltip 的品牌名同步改为 YRANDOM；
  - **仅改显示名**：插件 id（`ima.yrand`）、程序集（`ClassIsland.YRAND.dll`）、配置目录均未改动，老版本覆盖安装后设置项、名单、公平账本、统计数据全部保留，无迁移成本。

## 无行为变化

- 抽选流程、通知时机（整套过程结束后仅一条结果通知）、公平算法、麦克风加成、更新提示、匿名统计、Sentry 崩溃上报、悬浮窗右端居中与长按 2 秒拖动逻辑均与 v2.0.0.17 完全一致。

## 升级说明

- 从 v2.0.0.9~v2.0.0.17 任意版本直接覆盖安装即可；安装后 ClassIsland 插件列表中显示为 **YRANDOM**。
