# YRAND v2.0.0.17 修改说明

## 概览

本版围绕悬浮窗交互与可维护性做三处改动：**默认位置改为屏幕右端中间**、**拖动改为长按 2 秒后才能拖**、**接入 Sentry 崩溃上报**。

## 1. 悬浮窗默认位置：右端中间

- 首次运行（或未拖动过）时，悬浮窗默认出现在**主屏工作区右缘向内 24px、垂直居中**的位置，不再停在右上角。
- 采用 `Screen.WorkingArea` 计算，避开任务栏；多显示器取主屏；缩放（DPI）已换算为物理像素。
- 用户拖动过的位置仍按 `WindowX/WindowY` 保存恢复，不受影响。

## 2. 拖动逻辑：长按 2 秒

原逻辑"按下即可拖动"容易在点击抽人时误拖。新逻辑：

1. 按下开始 2 秒计时；
2. **按满 2 秒**进入拖动模式：光标变四向箭头、边框高亮加粗，此后移动即拖动窗口；
3. 长按期间移动超过 8px 视为放弃拖动（不拖动、松开也不触发抽选，防误触）；
4. 未满 2 秒且未移动的松开 → 触发抽选（点击语义不变）；
5. 拖完或松开自动恢复光标与边框，位置立即保存。

抽选进行中同样可以长按拖动，互不影响。

## 3. Sentry 崩溃上报

- 新增 `CrashReportService`：捕获 AppDomain 未处理异常、未观察的任务异常、Avalonia UI 线程异常，经 Sentry SDK（7.0.1，单 DLL 随包）上报。
- **开箱即用**：已内置作者 Sentry 项目 DSN，装上即上报；`CrashReportEnabled` 开关可整体关闭，`SentryDsn` 可替换为自己的项目（留空 = 不上报）。
- 上报内容仅异常堆栈与插件版本，不含名单与抽选记录；DSN 非法或网络不可达时静默降级，绝不影响插件功能；崩溃前有 3 秒 flush 窗口。
- 设置页新增「崩溃上报（Sentry）」卡片：开关 + 状态说明。

## 设置字段（settings.json）

| 字段 | 默认 | 说明 |
|---|---|---|
| `CrashReportEnabled` | `true` | 崩溃上报总开关 |
| `SentryDsn` | 内置作者项目 DSN | Sentry 项目 DSN，可替换或留空（留空 = 不上报） |

## 验证

- Release 编译 0 错误；包 12 → 13 个文件（新增 Sentry.dll），`version: 2.0.0.17`。
- Sentry 冒烟测试（沙箱 .NET 8 实测）：空 DSN 静默 no-op、非法 DSN 异常被捕获降级、合法 DSN 管道 CaptureEvent 正常入队。
- 长按拖动与点击语义的状态机：按下 → 2s 计时 →（移动>8px 取消）/（2s 到达进入拖动）→ 松开判定（拖动保存位置 / 未动触发抽选 / 放弃则双不触发）。
