# YRAND v2.0.0.9 修改说明 —— 通知逻辑重写

## 本次改动

按需求重写抽选过程中的通知行为：**整套抽选过程结束后才推送一次 ClassIsland 提醒并播报最终结果**。

| 场景 | 旧行为（v2.0.0.8） | 新行为（v2.0.0.9） |
|---|---|---|
| 第 1 段匀速滚动期间 | 提醒条下落显示「正在抽选 XXX」，原地实时换名 | **无任何通知，提醒条不下落** |
| 第 1 段定格、概率命中进入第 2 段 | 推送「已定格 XXX」并播报该名字 | **不通知、不播报，静默等待** |
| 第 2 段结束、概率命中继续滑 | 推送「抽选结果 XXX」并播报中间名字 | **不通知、不播报，静默等待** |
| 抽取过程结束（概率未命中 / 达到连续上限） | 推送「抽选结果 XXX」+ 播报 | 保留：推送 + 播报**最终结果**（唯一一次通知） |
| 等待期间点圆钮手动定格 | 播报当时定格名 | 保留：手动结束同样视为过程结束，立即播报 |
| 名单为空等错误提示 | AnnounceStatus 提醒 | 保留 |

## 实现方式

手上只有发布包（无 .csproj 源码工程），因此采用 **Mono.Cecil 对 DLL 直接打精准 IL 补丁**：

- 在 `ClassIsland.YRAND.Views.YrandWindow` 的 `Timer_Tick` / `Determine` / `AnnounceNext` 三个方法体中，删除对 `YrandHostService.AnnounceRolling(string)`（1 处）与 `YrandHostService.AnnounceHold(string, string)`（2 处）的 callvirt 调用及其参数装载指令，共 3 处、14 条 IL 指令
- 其余逻辑（状态机、概率判定、随机时长、反作弊、设置页、语音）**零改动**，与 v2.0.0.8 字节级一致
- `AnnounceRolling` / `AnnounceHold` 方法本身保留在 DLL 中（已无调用者，不影响运行）
- 补丁后已用 ILSpy 反编译逐方法核对：`Timer_Tick` 仅更新内部 `_currentName`；`Determine` / `AnnounceNext` 命中概率时只进入等待阶段，过程结束时调用 `Announce(text, 3.5)`

## 版本信息

- manifest.yml：`version: 2.0.0.8` → **`2.0.0.9`**（apiVersion 2.0.0.0 不变，id `ima.yrand` 不变）
- 描述已同步更新为新的通知行为
- README.md 通知相关段落已同步更新
- 包内不再附带 `.pdb`（调试符号，正式分发无需）

## 安装

`YRAND-2.0.0.9.cipx` 即 zip 格式，两种方式任选：

1. ClassIsland → 应用设置 → 插件 → 安装插件 → 选择该 `.cipx`（建议先卸载/禁用旧版 2.0.0.8 再装）
2. 解压后把整个文件夹放入 `data/Plugins/YRAND/`

## 建议重点验证

1. 点圆钮 → 滚动期间提醒条**完全不下落**、无声
2. 若命中滑动概率（进入第 2 段）：第 1 段定格的名字**不出现在提醒和语音里**，直到最终定格的那一位才一次性播报
3. 等待期间点圆钮：立即播报当时定格的名字
4. 若未命中概率：滚动结束直接播报抽中的人（与旧版一致的最终通知）
