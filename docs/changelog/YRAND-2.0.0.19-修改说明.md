# YRANDOM v2.0.0.19 修改说明

> 发布日期：2026-11-21 · 基于上一版 v2.0.0.18 叠加

## 本次改动

### 1. 修复长按拖动失效

- **根因一：取消阈值过严**。长按 2 秒期间指针只要累计偏移 ≥8px 就判为「放弃长按」，手部自然抖动即可误触发，导致按满 2 秒也无法进入拖动；本版放宽到 **24px**（明显滑动才算放弃）。
- **根因二：置顶维持打断捕获**。TopmostKeeper 每 2 秒做一次 Topmost 往返切换（z-order 变化），与长按计时几乎必然重叠，可能打断指针捕获；本版新增 `SuppressReassert` 开关，**按下期间暂停置顶维持**，松开恢复。
- **锚点防跳变**：进入拖动瞬间以当前指针位置重设锚点，窗口不再跳变。
- **捕获丢失自复位**：新增 `PointerCaptureLost` 处理，系统级打断后状态机自动复位，`_pointerDown` 不再卡死影响后续长按。

### 2. 更新提示改为独立可关闭窗口

- 原实现把更新提醒发进 ClassIsland 通知流（`AnnounceBackground`）；本版改为弹出**独立窗口 `UpdatePromptWindow`**：
  - 显示新版本号、当前版本、一句话更新说明；
  - 按钮「**前往发布台**」（打开国内发布台，附 sharecode 直达）、「**直接下载 .cipx**」（latest.json 的下载地址）、「**以后再说**」（关闭窗口）；
  - 标题栏带系统关闭按钮，随时可关；
  - 仍只在完全空闲时弹出（抽选进行中绝不打扰），已打开时仅激活不重复弹；
  - **空闲时不弹出则不记录已提醒**，忙时下一轮检查仍会提醒（比 v2.0.0.16 更可靠）。
- 设置页「插件更新提示」说明文字同步更新。

### 3. 品牌统一

- 过程通知前缀、通知提供方名称由 YRAND 同步改为 YRANDOM（v2.0.0.18 遗漏的两处显示名）。

## 无变化

- 抽选流程、通知时机、公平算法、麦克风加成、匿名统计、Sentry 崩溃上报均与 v2.0.0.18 一致。

## 升级说明

- 从 v2.0.0.9~v2.0.0.18 任意版本直接覆盖安装即可。
