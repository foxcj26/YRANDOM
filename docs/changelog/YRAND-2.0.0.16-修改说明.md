# YRAND v2.0.0.16 修改说明 —— 用户数量统计 + 插件更新提示

## 一、插件更新提示（新功能）

新增 `UpdateCheckService`：插件启动约 20 秒后（避开启动高峰）静默拉取发布台的
`latest.json` 更新清单，与自身版本号比对；发现新版本时提醒用户。

- **数据源走国内发布台**（`ade236ccde4e195c4.app.workbuddy.host`），课堂环境无须翻墙、
  不依赖 GitHub；清单地址记录在 `settings.json` 的 `UpdateChannelUrl`，可自行更换。
- **提醒策略（克制是第一原则）**：
  - 只在「无抽选过程通知且无占线通知」的完全空闲状态下弹出；
  - 抽选进行中或抽选结果通知还挂着时直接放弃本次提醒，**绝不打扰点名**；
  - 同一新版本只提醒一次（`LastNotifiedVersion` 记账）；
  - 更新提醒默认开启，可在设置页一键关闭（关掉后仅设置页显示版本信息）。
- 设置页新增「插件更新提示」卡片：当前版本 / 最新版本实时显示、
  「立即检查」按钮、提醒开关、更新方法说明。
- 全程 8 秒超时、失败静默；更新检查绝不阻塞启动与点名主流程。

## 二、用户数量统计（新功能，匿名）

新增 `UsageStatsService`：每天首次启动向计数服务发一次 GET 请求，
意义仅仅是「今天又有一台设备开了 YRAND」。

- **严格匿名**：不携带学生名单、机器名、设备号、IP 归属等任何个人信息，
  统计端只是一个累加数字。
- **频率有界**：每台设备每天最多计 1 次（`LastStatsReportDate` 记账）；
  上报失败当日不重试，避免刷量。
- 设置页新增「用户数量统计（匿名）」卡片：显示全球累计活跃次数、
  一键开关、匿名性说明。
- 默认开启（帮助作者了解插件使用情况）；关闭后本机完全不再联网上报。
  统计服务地址可在 `settings.json` 的 `StatsEndpointUrl` 修改或自建替换。
- 6 秒超时、失败静默；统计功能不影响插件任何其他功能。

## 三、工程与包变化

- 新增 `Services/UpdateCheckService.cs`、`Services/UsageStatsService.cs`；
  `YrandHostService` 挂载两个服务并新增 `AnnounceBackground()`（后台通知通道，
  空闲判定后走原有通知管线，不与抽选通知竞争）。
- `YrandSettings` 新增字段：`UpdateCheckEnabled`、`UpdateNotifyEnabled`、
  `StatsEnabled`、`UpdateChannelUrl`、`StatsEndpointUrl`、`LastNotifiedVersion`、
  `LastStatsReportDate`（旧字段全部保留，旧配置无损升级）。
- 设置页（YRAND）新增两张卡片：插件更新提示 / 用户数量统计。
- `manifest.yml`：version 2.0.0.15 → 2.0.0.16，描述补充新功能说明；
  `AssemblyInfo` 三处版本同步 2.0.0.16。
- 发布台新增 `latest.json` 更新清单（本插件更新检查的数据源）。
- 抽选状态机、公平算法、麦克风加成、通知防重复逻辑**全部未动**。

## 四、隐私边界（总结）

| 行为 | 时机 | 携带内容 | 可否关闭 |
|---|---|---|---|
| 更新检查 | 启动后 20 秒，每日每次启动 | GET latest.json（只读） | 可，设置页一键关 |
| 更新提醒 | 仅空闲且发现新版 | 本地通知一条 | 可（改为仅设置页显示） |
| 匿名统计 | 每天首次启动一次 | 无内容（纯计数 GET） | 可，关闭后零上报 |

## 五、安装与验证

- ClassIsland → 插件管理 → 本地安装 `YRAND-2.0.0.16.cipx`（建议先卸载旧版）。
- 重点验证：
  - 启动约 20 秒后设置页「插件更新提示」卡片显示「当前版本 v2.0.0.16 · 最新版本 v2.0.0.16（已是最新）」；
  - 点「立即检查」按钮能刷新版本信息（发布台可达时）；
  - 「用户数量统计」卡片显示累计活跃次数（统计服务可达时）；
  - 两项开关切换后重启，行为随之变化（关闭统计后本机不再上报）；
  - 抽选一切如旧：滚动、定格、连滑、结果通知均不受影响。

## 六、已知边界

- 更新检查与统计依赖网络：发布台或统计服务不可达时静默失败，
  设置页显示「暂不可达」提示，其余功能不受影响。
- 当前统计端点为公共免费服务（Abacus），如后续不可用，
  可改 `StatsEndpointUrl` 自建替换，无需更新插件。
